# Inventory Reservation System

A full-stack inventory reservation platform built using Next.js, Prisma ORM and PostgreSQL.

## Features

- Product inventory tracking
- Multi-warehouse management
- Inventory reservation system
- Real-time stock updates
- Reservation confirmation and release
- Responsive modern UI
- PostgreSQL database integration
- Prisma ORM support

## Tech Stack

- Next.js
- TypeScript
- Prisma ORM
- PostgreSQL
- NeonDB

### Reserve Inventory

### Confirm Reservation

POST /api/confirm

### Release Reservation

POST /api/release
